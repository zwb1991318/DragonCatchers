# Dragon Catchers（捞龙小队）游戏设计与总体规划

> 状态：v0.1 草案 · 2026-10-11
> 灵感来源：2011 年 Feelingtouch 的 iOS 游戏《Dragon Hunter》（已下架）。本项目只复刻玩法，不使用原版的任何素材。

## 1. 一句话定位

横屏卡通守城射击游戏：拉弓把来袭的龙射进河里，船自动把龙捞回来换金币，再用金币升级弓箭、船和城墙，一关一关打下去。

## 2. 核心设计决定

| 项 | 决定 |
|---|---|
| 屏幕方向 | 横屏（只支持横屏） |
| 射箭操作 | 拉弓式：按住屏幕往后拖，拖动方向决定瞄准方向，拖动距离决定力度；拖动时显示抛物线预瞄虚线，松手发射 |
| 船 | 自动打捞：龙掉进河后，船自己开过去捞。龙会被水流冲走，超时没捞到就没了 |
| 失败条件 | 守护城墙：龙飞近后会喷火攻击城墙，城墙 HP 归零就输，撑过所有波次就赢 |
| 美术风格 | 卡通，轻松明快 |
| 平台 | iPhone 优先，最低支持 iOS 17 |

## 3. 画面布局（横屏）

```
┌──────────────────────────────────────────────────────────┐
│ [城墙HP ████░░]   金币 120    波次 2/5          [⏸]      │
│                                        🐉 ←               │
│   🏹                              🐉 ←                     │
│  ███                                          🐉 ←        │
│  ███  城墙                                                │
│  ███                                                      │
│~~⛵~~~~~~~~~~~~~~~ 河（水流 →） ~~~~~~~~~~~~~~~~~~~~~~~~~~│
└──────────────────────────────────────────────────────────┘
```

- **左侧**：城墙，弓箭手站在墙头。
- **底部**：一条横贯全屏的河，水流从左往右，船停在城墙脚下的码头。
- **右侧和上方**：龙分波次从这里飞进来，飞向城墙。
- **顶部 HUD**：城墙血条、金币、波次进度、暂停；从 M3 开始加技能按钮。

## 4. 核心循环

```
射龙 → 龙掉进河 → 船捞龙 → 运回码头换金币
  ↑                                    ↓
进入下一关（更难）  ←  过关后在商店升级
```

- 单局压力：龙在逼近城墙，要优先射离墙近的龙。
- 单局取舍：已经落水的龙要赶在被冲走前捞上来，船的效率决定能赚多少金币。
- 长期成长：金币用来升级，升级后才能打下更难的关卡。

## 5. 系统需求

### 5.1 射击
- 拉弓输入：按下开始蓄力，拖动时更新方向和力度，松手发射；力度有上限。
- 抛物线预瞄虚线，长度可以作为升级项。
- 装填间隔：发射后要等一段时间才能再射。
- 箭受重力影响飞行，箭头朝向跟着速度方向转。
- 命中判定和伤害；箭飞出屏幕或落进河里后自动消失。

### 5.2 龙
- 属性：血量、飞行速度、飞行路径（直线或波浪）、攻击距离、攻击力、攻击间隔、掉落金币。
- 行为：飞进屏幕 → 飞向城墙 → 进入攻击距离后悬停并喷火 → 被击落后下坠 → 落进河里。
- 种类（M3 全部做完）：

| 种类 | 特点 |
|---|---|
| 普通龙 | 基准数值 |
| 快速小龙 | 血量少、速度快、金币少 |
| 装甲龙 | 血量多、速度慢 |
| 远程喷火龙 | 在较远处停下，用火球攻击 |
| Boss | 血量很多，会召唤小龙，有特殊攻击 |

### 5.3 河与船
- 落水的龙随水流向右漂，漂出屏幕就没了。
- 船自动选择目标：优先捞最快会漂出屏幕的龙，这个策略后续可以调整。
- 船有速度和载量，满载或河里没有龙时就回码头卸货结算。

### 5.4 城墙
- HP 和受击反馈（闪红、震动）。
- 修理：作为升级项，或者在关卡之间用金币修。

### 5.5 关卡与波次
- 每关由若干波组成，每波写明龙的种类、数量和出场间隔。
- 全部用数据文件配置，不写死在代码里。

### 5.6 经济与升级

| 类别 | 升级项 |
|---|---|
| 弓箭 | 箭伤害、装填速度、多重箭、特殊箭（毒箭持续掉血、眩晕箭让龙停住、火箭溅射伤害） |
| 船 | 船速、载量 |
| 城墙 | HP 上限、自动修墙 |

每项升级的价格逐级上涨，具体曲线放在数据文件里调。

### 5.7 技能（法术，有冷却时间）
- 火雨：对一片区域造成伤害。
- 冰冻：所有龙减速或停住几秒。
- 狂风：把龙往后吹退。
- 闪电：对单个目标造成高伤害，可以连锁到附近的龙。

### 5.8 存档
关卡进度、星级、金币、各项升级等级。

### 5.9 界面
主菜单、关卡选择、游戏内 HUD、暂停、胜利和失败结算、商店。

## 6. 技术架构

### 6.1 技术选型
- **Swift + SpriteKit**：游戏场景用 SpriteKit，靠它的物理引擎做箭的抛物线和龙下坠。
- **SwiftUI**：主菜单、商店、结算这些界面用 SwiftUI，通过 `SpriteView` 嵌入游戏场景。
- **XcodeGen**：工程配置写在文本文件 `project.yml` 里，便于修改和版本管理；生成的 `.xcodeproj` 不放进 git。
- **单元测试**：用 Swift Testing 或 XCTest。

### 6.2 目录结构

```
DragonCatchers/
  project.yml
  App/            SwiftUI 入口、菜单、商店
  Game/
    Scenes/       GameScene（一关的主场景）
    Entities/     Archer, Arrow, Dragon, Boat, Wall, River
    Systems/      WaveSpawner, CollectionSystem, Economy
    Input/        拉弓手势
  Data/           levels.json, dragons.json, upgrades.json
  Model/          纯逻辑：存档、升级曲线、波次解析（不依赖 SpriteKit）
  Tests/          单元测试
  docs/           设计文档
```

### 6.3 设计原则
- **数据驱动**：数值都放在 JSON 里，调手感时不用改代码。
- **逻辑和画面分离**：经济、升级、波次、弹道计算写成纯 Swift，可以单元测试。
- **一个文件只管一件事**：每个实体和系统都独立成文件，方便逐个修改。
- **美术先用占位图形**，到 M4 再换成卡通素材（来源：Kenney.nl、itch.io，或者 AI 生成后再调整）。

## 7. 里程碑路线图

| 里程碑 | 内容 | 完成标准（你可以自己验证） |
|---|---|---|
| **M0 工程搭建** | XcodeGen 工程、git、空的横屏场景 | 模拟器里能打开一个横屏的空场景 |
| **M1 核心循环** | 一关完整流程：拉弓射箭和预瞄线、龙分波来袭并喷火、龙落河漂流、船自动捞、金币结算、输赢判定。用彩色方块代替美术 | 能完整玩一关并赢或输，手感经你确认 |
| **M2 成长系统** | 商店和升级（伤害、装填、船速、载量、城墙 HP）、存档、10 个关卡、关卡选择 | 关卡之间能升级，退出后再进进度还在 |
| **M3 内容扩充** | 5 种龙、特殊箭、4 个技能、Boss，扩充到 30 关、3 个区域 | 每个区域末尾有 Boss，难度曲线经你试玩认可 |
| **M4 美术和音效** | 卡通美术、动画、音效、音乐、打击感（震屏、粒子） | 看起来像个成品 |
| **M5 上架准备** | 图标、确认商店里没有重名、真机测试、TestFlight 和 App Store 提交 | 上架或在 TestFlight 上可用 |

每个里程碑开始前，会先单独写一份详细的实现计划。

## 8. 暂不做的事

内购和广告、联网和排行榜、iPad 专门适配、多语言（先只做中文）、安卓版。这些等 M5 之后再考虑。

## 9. 版权原则

复刻的只是玩法。名字、美术、音效全部原创或者使用允许商用的素材，不用原版的素材，也不用 "Dragon Hunter" 这个名字。
